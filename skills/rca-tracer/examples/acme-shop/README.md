# Example: Acme Shop (fully fictional)

This is an invented system used to show one complete rca-tracer run. Every name,
path, and line here is made up. Nothing in this folder refers to a real company,
product, or repository.

Acme Shop is a small online store with four repositories:

- `web`: the browser client
- `api`: the public HTTP API
- `service`: business logic
- `data`: database access

## Files in this example

- `repo-map.md`: the filled-in repository map for Acme Shop.
- `layer-map.md`: the filled-in layer map.
- `trace.md`: a worked trace from a symptom to a confirmed root cause, with the
  hop ledger, the five guards, and fix options.

Read `trace.md` to see the method end to end.
